Hướng dẫn Triển khai (Deployment) & Lưu trữ Đám mây Miễn phí 100%

Hướng dẫn từng bước chạy Local, đưa lên GitHub Pages / Vercel / Netlify và kết nối Firebase Spark miễn phí

1. Cách chạy thử ngay trên máy tính cá nhân (Zero-Build)

Bước 1: Tải hoặc lưu toàn bộ mã nguồn ứng dụng thành một tệp duy nhất tên là index.html trên máy tính của bạn.

Bước 2: Nhấp đúp chuột trực tiếp vào tệp index.html để mở bằng Chrome / Edge / Safari / Firefox, hoặc mở thư mục trong VS Code và nhấn Go Live (Live Server) ở góc dưới bên phải.

Bước 3: Toàn bộ chức năng soạn thảo văn bản, tạo Không gian vẽ 3 lớp, Pan/Zoom bên trong khung vẽ, lưu tự động qua IndexedDB + LocalStorage và xuất file .pdf, .doc, .dcanvas đều hoạt động 100% ngay lập tức mà không cần cài đặt Node.js hay chạy lệnh build.

2. Cách đẩy code lên GitHub và triển khai miễn phí lên GitHub Pages / Vercel / Netlify

Cách A — GitHub Pages (Miễn phí vĩnh viễn):

git init
git add index.html
git commit -m "Deploy DocuCanvas Studio SPA"
git branch -M main
git remote add origin https://github.com/<ten-tai-khoan>/docucanvas-studio.git
git push -u origin main

• Sau khi push, vào kho lưu trữ trên GitHub → Settings → Pages → tại mục Branch chọn main / /(root) → nhấn Save. Sau 1 phút, trang web của bạn sẽ có địa chỉ công khai: https://<ten-tai-khoan>.github.io/docucanvas-studio/.

Cách B — Vercel hoặc Netlify (Kéo-thả trong 15 giây):

• Truy cập https://vercel.com (Import GitHub Repo vừa tạo và nhấn Deploy) hoặc vào https://app.netlify.com/drop và kéo-thả trực tiếp thư mục chứa index.html vào trình duyệt để nhận ngay tên miền HTTPS miễn phí.

3. Cách kết nối Cơ sở dữ liệu Đám mây miễn phí (Firebase Auth + Cloud Firestore Gói Spark)

Bước 1: Truy cập https://console.firebase.google.com/ → nhấn Create a project (chọn gói Spark Plan — Miễn phí $0/tháng).

Bước 2: Ở menu bên trái, chọn Build → Authentication → nhấn Get started → bật Email/Password và Google Sign-In (thêm tên miền GitHub Pages / Vercel của bạn vào mục Authorized domains).

Bước 3: Chọn Build → Firestore Database → nhấn Create database → chọn Start in test mode (hoặc cấu hình Rules cho phép request.auth != null).

Bước 4: Vào biểu tượng Bánh răng Project Settings → cuộn xuống mục Your apps → chọn biểu tượng Web </> → đăng ký tên app và sao chép đối tượng JSON firebaseConfig.

Bước 5: Quay lại giao diện DocuCanvas Studio → nhấn nút Cloud DB trên thanh Header → dán đoạn firebaseConfig vào ô cấu hình và nhấn Kết nối & Đồng bộ Cloud. Hệ thống sẽ lập tức đồng bộ toàn bộ tài liệu và các lớp vẽ lên Cloud Firestore theo thời gian thực!
